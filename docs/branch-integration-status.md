main 목표 Manifest와 통합 브랜치의 목표 Manifest는 같다. 개발 BE는 `08e8a5720430`, AI는 `54cc4581f40a`, FE는 `18a947df7c8d`다. 이는 저장소의 배포 목표이며, 이번 Git 통합에서 AWS의 실제 실행 버전을 다시 검증한 것은 아니다.

개발 모니터링은 [10월 20일 적용 기록](dev-monitoring-connection.md)에 따라 이미 AWS에 연결됐다. PR #112는 그 구성을 재현·관리할 소스의 main 반영 건이며, 현재 동작의 선행 조건은 아니다. 이번 통합에서는 AWS 설정 변경이나 앱 재배포를 실행하지 않았다.

다른 로컬·원격 브랜치의 파일 목록도 대조했다. 누락됐던 V2 문서는 보존했으며, 폐기된 `schedule-probe.yaml`, 구형 `production-manifest.yaml`, `validate-manifest.py`는 복원하지 않았다. ECR·FE 등 이미 main에 반영된 코드에는 최신 main을 우선했다. 기존 자동배포·상태 확인 workflow와 배포 스크립트의 설명 주석은 통합 브랜치에 유지한다.

ECR push 즉시 실행과 10분 주기 보조 실행은 유지한다. 주기 삭제는 적용하지 않았다. 최신 적용 이력은 [V2 개발 CD 작업 정리](v2-dev-cd-work-summary.md), 개발 수집의 설치·복구 방법은 [개발 모니터링 운영 절차](dev-monitoring-runbook.md)를 따른다.
